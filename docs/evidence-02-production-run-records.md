## 0. 统计口径（可复现）

- 计数基于 `tasks` 表 `created_at`（按自然日 `::date`），状态为终态值（`completed/failed/timed_out/cancelled`）。
- `tasks` 表**不记录节点当时的 agent 版本**，因此"任务归属哪个版本"按**创建日 × 版本部署时间线**近似归属（见 §3 时间线）。
- 核验所用 SQL（结果见下各表）：

```sql
select (created_at::date) d,
       count(*) n,
       count(*) filter (where status='completed') done,
       count(*) filter (where status='failed')   fail,
       count(*) filter (where status='timed_out') to_,
       count(*) filter (where status='cancelled') canc
from tasks group by 1 order by 1;

select agent_id, count(*) n,
       count(*) filter (where status='completed') done,
       count(*) filter (where status='failed') fail
from tasks group by agent_id order by n desc;
```
